# NOCTIS — исследуй ночное небо

Учебный адаптивный лендинг о начале любительских астрономических наблюдений.

## Состав проекта

- `index.html` — структура и содержание сайта.
- `styles.css` — оформление, цвета, сетки и адаптация для мобильных экранов.
- `script.js` — поведение мобильного меню.
- `images/` — папка для изображений проекта.

## Запуск

Откройте `index.html` в браузере. Для публикации через GitHub Pages выберите ветку `main` и папку `/ (root)` в настройках Pages.
