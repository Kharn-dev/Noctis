# Изображения проекта

Поместите сюда изображения, которые будут добавлены или обработаны с помощью ИИ-агента для лабораторной работы.

Для отчёта сохраните:
- исходные изображения;
- результат работы агента;
- скриншот промта;
- скриншот этой папки с готовыми изображениями.

Пока папка намеренно не содержит вымышленных изображений.
